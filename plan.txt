PROC (name TBD) - plan
======================

GOAL
  A simple "what's running that I care about" CLI for Linux.
  One command -> short tables -> PID/name you can kill.
  Not a live monitor: no graphs, no per-core CPU (that's htop/btop).

  Also: learn C + Linux internals, publish on GitHub, resume-quality
  (tests, CI, packaging).

PRINCIPLES
  - Linux only. Read /proc and /sys directly, no heavy deps.
  - Default = one-shot table output, readable and scriptable.
  - Hide noise by default (kernel threads, system daemons); --all shows it.
  - Small, tested modules.

WHAT WE TRACK
  apps        things with a window: firefox, spotify, alacritty -> nvim
              rule: your process whose executable matches a .desktop file
              (freedesktop standard: works on any compositor, X11, any distro)
              children rolled up (count, mem)
  services    everything running under the hood, for inspection
              user:   your processes that are not apps (waybar, mako,
                      wireplumber, syncthing)
              system: system.slice/*.service from /proc/<pid>/cgroup
                      (docker, libvirtd), minus an "essentials" list
                      (systemd-*, dbus, NetworkManager, udev, logind...)
  containers  running docker containers (name, image, ports, status)
  ports       listening TCP/UDP sockets -> pid/process

  always hidden: kernel threads (ppid 2), PID 1

  caveat: an app without a .desktop file shows under services
          (fix later with a config option)

  ideas (pick later):
  databases   mongod, mariadbd, postgres, redis... (native or docker)
  dev servers node/python/java processes + their project dir (/proc/pid/cwd)
  orphans     dev processes re-parented to PID 1 after their terminal closed
  zombies     defunct processes and which parent isn't reaping them
  failed      systemd services that crashed
  sessions    tmux/screen sessions, ssh logins
  tunnels     ssh port-forwards, VPN/wireguard interfaces
  vms         libvirt/qemu guests
  gpu         processes using the GPU (nvidia/amd)
  mounts      FUSE / network mounts (sshfs, nfs, smb)

STAGES
  0. skeleton            Makefile, main.c, debug build          [done]
  1. MVP                 apps + services + containers + ports   [done]
       1a procfs         read /proc/<pid>/stat,status,cmdline  [done]
       1b desktop        index .desktop files -> set of app executables  [done]
       1c classify       per process: app / service / hidden (cgroup, uid)  [done]
       1d apps           roll children up under each app, terminal -> job  [done]
       1e services       user + system, essentials filter  [done]
       1f ports          /proc/net/tcp{,6} + fd inode -> pid  [done]
       1g docker         `docker ps --format` via popen  [done]
       1h table          aligned columns  [done]
       1i tests          fixture /proc + assert harness  [done]
  2. kill                proc kill <pid|name|port>, whole tree,
                         TERM -> KILL, confirm, protect PID 1/shell
  3. databases           name + port + image detection,
                         kill via systemctl / docker stop
  4. polish              --json, --sort, --all, find <name>, colors,
                         config file (custom signatures)
  5. publish             README + demo gif, man page, CI, releases, AUR
  6. maybe               interactive TUI (ncurses), docker via socket,
                         PSS memory, extra trackers from ideas list
